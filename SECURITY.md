# Security Policy

This repository contains Intel packaging and license-compliance artifacts for
the **ucx-ze-builder** container image (a Docker CI/build image for UCX with
Level Zero support).

## Reporting a Vulnerability

Report security vulnerabilities in the ucx-ze-builder container images to the
Intel Product Security Incident Response Team (PSIRT):

- https://www.intel.com/content/www/us/en/security-center/default.html

Please do not report security vulnerabilities through public issues.

## Scope

- **ucx-ze-builder container images** (`intel/ucx-ze-builder` and
  `intel/ucx-ze-builder-sources`): report via Intel PSIRT as above.
- **UCX source code**: this project builds UCX from the upstream community
  project. For vulnerabilities in UCX itself, see the upstream project's
  security policy: https://github.com/openucx/ucx
- **Level Zero**: built from Intel's upstream https://github.com/oneapi-src/level-zero
